# Limitations and future work

Complete this file based on the actual build. Possible limitations to discuss where applicable:
- Sensor offset/gain and calibration uncertainty
- ACS712 noise and zero-current offset
- Voltage-based SOC sensitivity to battery chemistry, load, and rest conditions
- SOH requires a defined capacity test for meaningful validation
- Relay module ratings, switching transients, and safe cutoff behavior
- Dashboard connectivity depends on Wi-Fi and service availability
- A student prototype is not a certified battery-management or safety system

Possible future work (mark as planned until implemented): calibrated coulomb counting, capacity-based SOH testing, logging, improved fault handling, watchdogs, and a validated protection stage.
