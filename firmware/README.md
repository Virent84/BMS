# Firmware

Place your original Arduino IDE `.ino` sketch(es) here. Keep a separate backup of the original files before editing.

## Before publishing
- Remove real Wi-Fi passwords, Blynk tokens, API keys, and private identifiers.
- Document the exact ESP32 board and required library names/versions.
- Record which sketch is the main working version.
- Compile and test the public version after any changes.
- Keep experimental sensor-test sketches clearly named, e.g. `test_ads1115.ino`.

## Important Arduino IDE note
For a sketch to open normally in Arduino IDE, the main `.ino` file should be inside a folder with the same name. If you have a sketch called `SmartEVBMS.ino`, the conventional layout is `firmware/SmartEVBMS/SmartEVBMS.ino`.
