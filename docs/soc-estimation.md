# SOC and SOH estimation

## State of Charge (SOC)
Document the exact method used in the firmware. A voltage lookup is only a rough estimate and depends on battery chemistry, temperature, load, and rest time. A regulated 12 V adapter is not a battery and cannot be used to demonstrate meaningful battery SOC.

## State of Health (SOH)
A credible capacity-based SOH estimate generally needs measured usable capacity compared with the rated/reference capacity under a defined test procedure. If the project only uses voltage/current/temperature snapshots, label SOH as experimental, simulated, or planned—not validated battery health.
